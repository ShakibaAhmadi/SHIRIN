

# SHIRIN — Semi-anthropomorphic Human-Interactive Robot & Intelligent Narrator

SHIRIN is a non-humanoid theatrical social robot developed as part of a
Master's thesis in Automation and Control Engineering at Politecnico di Milano.

The project explores how emotion, mood, personality, memory, and physical
expression can be integrated into a social robot and used in a theatrical
context.

## Repository Structure

- `python/` — Python software and robot behavior
- `arduino/` — Arduino/embedded control code

## Main Features

- Emotion and mood representation
- Personality-driven behavior
- Facial and person detection
- Physical emotional expression
- Autonomous movement
- Obstacle avoidance
- Human–robot interaction
- Theatrical performance
